## 推力模型应怎样理解

已知物理参数时，T_i = rho * n_i^2 * D_i^4 * CT_i(J_i,Re_i,M_i; geometry)。
n以转/秒计，不能把事件频率直接塞入n：事件峰、叶片数、谐波/极性可能产生歧义。
同机常采用同型桨，转速不同已经足以使四桨推力不同；不必无证据给四个桨设四种翼型。

叶素公式：
T = B * integral[0.5*rho*W(r)^2*c(r)*(Cl(alpha,Re)*cos(phi)-Cd(alpha,Re)*sin(phi)) dr]。
c(r)是弦长分布，alpha=beta(r)-phi(r)，beta是桨距/扭转角；
W和phi需要轴向来流、切向速度与诱导流。叶素动量理论求解诱导流后才得到合理推力。
旋转事件形成的椭圆给出桨盘投影，不能由此直接读出弦长、翼型截面和扭转分布。
当前RAW未知物理尺度/桨型，先维持相对推力输入和有效图像增益；已知模型时可接实测CT曲线。
模块支持静态RPM/CT表插值，禁止无提示外推；非静态来流需要J相关数据，不能冒用静态曲线。

四桨合力F=sum(T_i*n_i)，力矩tau=sum(r_i cross (T_i*n_i)) + reaction torques。
普通平行桨轴时F=(sum T_i)*n，推力差改变力矩，不直接产生四个不同的合力方向。
当四桨始终齐全且系数一致时，mean(f_i²)与sum(f_i²)只差常数，可被有效增益吸收；改名求和本身没有新增预测信息。
真正新增信息是差分力矩→未来角运动→未来法线→未来平移加速度。当前RAW主干尚未把差速力矩用于未来法线演化。
本轮逐桨状态为这条链路保留信息，已知参数反解接口不等于该链路已经完成。

## 缺桨推断的资格

单帧姿态只约束方向，不给出总推力。连续姿态可估角速度/角加速度，但还需惯量/力臂/外部力矩或有效标定：
tau = I*angular_acceleration + omega cross I*omega - external_torque。
三桨已知加一条有效独立力矩约束可求缺失项；两桨需要足够独立方程。
二维单一角度通常只提供一个角加速度约束，不能自动解两个未知推力。
离线模块infer_missing_thrust采用非负最小二乘、显式先验与数据矩阵秩：
欠定时仍能给先验条件解，但不标成唯一观测；未标定的姿态角不作为力矩输入。
当前RAW分支没有偷偷加入真实惯量或机械姿态真值，力矩约束接口尚未由视觉独立标定。

## 当前主要限制与后续实现顺序

1. 拆粘连与短弧影响可见集合和重复/漏计；编号置换本身不影响同型全桨合力。无四桨锁定时，圆饼轴线仍可用于轨迹方向演化。
2. 频率可靠性：另一录像180时刻无合格周期。公式在没有可用输入时无法提供先行物理响应。
   已做固定40–46秒全像素RAW对照，保留全部原始时间；最多恢复15个周期像素、同频簇最多8个，未过16像素门槛，仍无合格周期；采样增加支持但不足以解决零输入。
   原框中位约191×82px，也不能直接说只是目标太小；需查平移导致固定像素周期消失、对比度、谐波和观察器假设。
3. 独立状态/标定：先对稳定电机身份得到的频率及轴线变化，学习可辨识的有效角响应；不强求质量、桨距、风速分别收敛。
   平移继续使用已知输入＋未知合力；转动增加未知合力矩项，二者单位与作用不同。
   将差速力矩、角运动、未来法线接入预测积分，才能在总推力近似不变而开始倾转时保留提前响应。
4. 检测前端：重叠频率区域需分层、运动补偿后提取真实弧支持；隐藏桨不当作观测，侧视不强补四桨。
5. 性能：逐桨状态新增开销小，主要仍是几何/周期/NN和突发解码。吞吐、当前Hz、启动与延迟分开。
