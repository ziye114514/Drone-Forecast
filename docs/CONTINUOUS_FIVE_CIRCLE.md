## 这批实现

图像模型为`p_i = c + A r_i`，共享状态六维：中心c的两个分量、二维仿射A的四个分量。r_i是首次四桨确认时的相对模板，尺度任意；不是已知真实机架尺寸。保持同一模板，不随四/三/两/轴线的观测模式切换重置对象。

* 四个当前合格桨心：初始化后更新同一状态，而非每帧换模板。
* 三个非共线合格桨心：最多六个图像约束，结合已有形状/匹配边界更新；缺点永远是预测点。
* 两个非扁平合格桨心：四维信息更新，剩余方向保留不确定性。`partial_two`不是已证明的侧飞。
* 退化轴线：一维角度约束，共享状态随当前轴线更新；没有把未观测长度、隐藏桨心重新测一遍。
* 无当前支持：模板可短时保留作推测；当前证据持续合格时可续接。身份变化或长时间整机丢失清除模型。

沿用原四桨双确认、.6–1.6变形边界、.65–1.5形状输运比、8px/.6桨径匹配门控。新增协方差是启发式近似，不能称为已校准置信区间。弱透视仿射不能代表完整透视/三维姿态，圆盘中心也不等于真实质心。

## 条件中心与位置

两桨信息更新产生的`model_conditioned_center`依赖已确认模板和当前两点。它与`current_geometric_center`分开，后者在两点情形仍为空，`model_conditioned_center_is_current_measurement=false`。仅当前局部匹配合格、已有四桨坐标偏移参考、最大中心方差代理<=36px²时，才以低权重CI影响p/v初态。不从隐藏点生成位置观测或频率。
