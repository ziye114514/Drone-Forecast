# 50px / 30FPS候选（2026-10-28）

本地研究入口，不替换已发布的v0.4.0-alpha.1 ZIP。

最新联合配置追加 `--rigid-motion --tangent-disturbance --structure-guided-nn --sdk-avx2`（本机SDK编译前提不变）。固定8秒240源、174当前、170有效预测均保留，26目标均值43.27px、P9580.60px，16/26低于50；原4秒43.74px/35.41处理FPS，新4秒42.23px。清晰段同数值薄线融合后32.94处理FPS。初期仍有约610ms积压，后续恢复。train2最新62.65px、0周期输入，仍未达标。下列历史结果保留以追溯增量。

新改动针对可靠框之间的可见范围变化：旧局部框与新完整框包含、当前点轨迹可靠时，允许使用已测事件速度，而不把框中心的校正当成物体瞬间运动。只放行相容的强检测框，弱旧框、旧NN、无轨迹和无界框增长反例拒绝。切向未知力只更新法线正交的一个分量，不虚构沿法线推力。结构指导NN刷新只减少冗余神经请求，RAW/几何/周期时刻全保留。

## 已完成的实际结果

- train6侧视110–114秒：120源、114当前观测、110有效预测；0.4秒18个开发目标，均值47.21px、P9583.84px、9/18小于50px。处理能力36.88FPS，实际当前观测28.40Hz；初期积压数百毫秒，末10时刻12–27ms。
- 同一最新观测：不复用位移的二力控制63.31px；校正外推速度48.28px；再加同窗口未知力反馈47.21px。主要修复弱框升级可靠NN框时，定位中心校正被当成真实速度的问题。位置状态、有效资格和评分时刻不变。
- 清晰26–28秒有四/三/部分二桨输出，没有独立人工位置参考。短测曾达到30.41处理FPS；最新自适应/SDK AVX2组合29.99FPS，串行组合28.34FPS，均有初期积压。不能四舍五入宣称稳定30FPS。
- train2目前约60px，0合格周期推力输入，迁移段尚未达标。

**均值达到50px不代表每次都在50px内，也没有证明稳定全程30Hz或未知录像泛化。**

## 预测逻辑

1. 原生RAW、活动噪声过滤、20ms ON/OFF计数和当前整机ROI，不用G通道重建。
2. 原弧/椭圆计算桨心；四桨确认共享五圆，三桨条件补全；两点只更新可观测部分，侧线只更新当前轴，不冒充完整平面。
3. 每像素周期条件代理与当前法线构成相对输入，不能称独立真实RPM或牛顿推力。
4. 一个位置/速度状态。复用定位已有的双向KLT位移校正速度，过去合格位移估计总图像加速度，不再计算光流或建立位置KF。
5. 当前可靠NN框接替旧弱框时，以当前轨迹及投影框重叠确认速度。中心校正不是物体瞬间运动，旧弱框也没有被改标成可靠检测。
6. 同一时间窗速度扣除已知输入积分后，估计二力模型的未知项，避免把当前推力从过去平均加速度中硬减。
7. 当前轴合格、周期短暂缺失时，用最多0.12秒的旧幅值加当前方向；旧幅值不参与转速增益或输入积分学习，不自我续期。

## 本机运行

已配置SDK/GPU Python；可选依赖见requirements-counts.txt。EDF_NUMBA_PATH指向隔离依赖目录，SDK NumPy没有改动。

```powershell
$env:EDF_NUMBA_PATH='<隔离Numba目录>'
& '<SDK Python>' -X utf8 run_fast_structure.py `
  --raw '<event.raw>' --output '<新的结果目录>' `
  --start 110 --duration 4 --target-candidate --paced
```

--target-candidate聚合当前候选；原--goal-profile、--reference-compute、同步/串行控制保留。
--legacy-motion-anchor-gate恢复旧的弱前框速度拒绝规则。
默认没有旧v7并行预测器，--with-kinematic-control只供显式研究对照。
--verify-frames是额外调试哈希，功能核验和生产计时需分别披露。

可选--sdk-avx2调用本机SDK头文件的本地编译实例。需MSVC、Python头文件、pybind11与合法SDK，构建工具为tools/build_sdk_activity.py，目前仍是本机SDK路径。
SDK头文件没有复制到项目，私有编译二进制不进入发布包。SDK CV不能说成OpenEB开源模块。
三个原生窗口过滤耗时约减半，事件字段、顺序和跨分块状态一致；完整60帧最终预测不变。但完整流水线速度受其他组件影响，不等于翻倍。

## 计算与未解决问题

融合原生ROI/计数、占用图、最新像素周期索引，保持原字段/像素顺序；同10个中心差分点计算椭圆不确定度，缓存固定模板设计矩阵。原函数仍保留。JIT预热可写与只读SDK数组签名，避免第一批输入触发额外编译。

循环GC只在有限回放流内延后，引用计数释放不变，结束恢复；没有验证无限流内存稳定，也没有证明所有慢帧都由GC造成。
summary.json包含每帧日志/可选视频服务时间；timings.jsonl在定时流结束后保存完整逐帧耗时。早期predictions.jsonl在写入完成前序列化，不含自身尚未知的output_ms。

局部增益试验真实25个候选信噪比均小于2，0次合格更新。不要通过放宽门槛宣称学出了推力系数。
初期大事件突发仍积压，图像预测可能混入相机运动；stage103已有背景相位相关诊断可复用，未经核验不能直接相减。
后续优先转向误差长尾、无周期段和突发服务时间，保留小收益，用实际改动推进。
