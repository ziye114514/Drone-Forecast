## 仍缺的连接，以及建议实施顺序

1. **先把显示做真实**：分别输出原始ON/OFF、密度过滤后ON/OFF、严格周期通过像素图，以及用于几何的支持引导原生弧图。标清膨胀/闭运算/历史累计像素，不能当成当前实测桨叶像素。现有叠加图仅作调试视图。
2. **补回有依据的桨盘弧**：周期像素用于发现和确认区域，回到该区域的原生ON/OFF弧段取几何证据，不用周期掩膜硬切出假的轮廓。不要仅从已被严格周期筛掉的大半轮廓上反复拟合圆，也不要认定所有场景尺度绝对不可观测。
3. **明确运动阶段的输入**：把“桨叶支持用于定位”和“附近原始纹理用于匹配”的贡献分开，比较支持加权的位移估计。维持因果更新、失锁重发现，不要求整机NN提供ROI才能工作。
4. **再接可见性与替代输入**：4/3/2只在相应证据足够时输出；线状侧视不强迫凑四桨/完整五圆。与保留基线做同检测位置、同实际查询+0.4秒的短对照，直接检验预测收益。

周期性非桨背景对照仍不足，意味着尚未验证误报边界，不应据此声称泛化稳定；这也不意味着必须等用户补拍才能继续实现显示、弧段提取或诊断。当前失败仅适用于已试配置与短片，不能把“门控试验更差”写成桨叶路线没有价值。
