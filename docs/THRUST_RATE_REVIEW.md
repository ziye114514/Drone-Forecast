## 上一时刻推力与变化率的作用

已有代码利用过去已知输入的时间积分、成熟自身位移和近期速度来估计参数/未知合力；当前速度包含过去运动的结果。
默认未来预测包括当前合力、合力持续性和已观测平面法线趋势。推力幅值导数此前仅有可选实验，没有默认启用。

设总推力向量F_T=T*n，n为机体平面单位法线：

    dF_T/dt = (dT/dt)*n + T*(dn/dt)
    jerk = ((dT/dt)*n + T*(dn/dt))/m + d(unknown acceleration)/dt
    p(t+h) ≈ p + h*v + (h²/2)*a + (h³/6)*jerk

这是局部展开，用来解释预测项；程序仍用有界解析积分，不把线性斜率无限持续。
总推力大小不变、机体倾斜改变时，第二项仍然改变未来运动；头尾和桨盘编号不参与该关系。
未知质量/投影尺度下，实际采用a_image=k*q*n+d，q为相对f²代理，固定当前k来估计其变化率；参数重标定的k变化不能当成真实推力变化。

## 本轮具体实现和结果

`SourceAwareThrustTrendForecast`分别维护实际测得的完整四桨和整机代表周期历史。
选择器某时刻用了不完整桨集合时，独立合格的整机周期仍可积累自己的历史；但其变化率只用于当前匹配的整机周期输入，不借给未识别的部分桨均值。
使用最近0.35秒可信同源观测，至少6次/0.16秒；短缺测不立即清空，超过0.12秒或明显频率跳变重新开始。噪声收缩、未来0.4秒幅值0.8–1.25倍边界保持原值，没有扫标框调参。
未知力不随推力幅值一起缩放，法线变化项仍由已有方向模块处理，避免重复计算。

固定已保存输入的试验：侧视可应用变化率的时刻4→56，0.4秒均值34.6048757→34.6049175px，实用精度没有改善。
另一录像变化率仍0次，误差59.7895553px不变。此结果说明输入与预测项的衔接更完整，不说明精度成功提升。
试验没有重跑RAW或测FPS；变化率组件CPU均值约0.05ms，仅是本机组件时间。
原生周期观测仍是默认，变化率功能保持`--thrust-trend-forecast`显式实验。原默认轨迹没有变化。

受控检查涵盖独立周期历史、缺测/几何重置、恒定频率零变化率及幅值/方向/固定未知力的数值积分。
