# 五圆共享几何与批量空间相位（实验模块）

> 2026-11-01阶段163更新：已接入rotor-only当前频率选择，支持部分槽逐步校准，并排除未来/重复过去区间。此前日志根据静态环闪烁得出“方向性判据不可达”的判断已纠正；真实旋转/平面摆动正例通过，方向守卫仍保留。当前41次清晰槽资格、30次参与选择，侧视0次。详见HANDOFF_20261101_PHASE_SPEED163.md；下文为先前独立模块记录，不能把历史“未接默认”当成现状。

当前生产入口仍用已完成的SDK像素周期链路。这里是独立模块实验，不默认更换推力输入。
不需要作者DLL的实现为 `shared_phase_fft.py`；NumPy/SciPy即可运行合成检查，真实RAW读取仍需SDK。

## 做法

从四个当前合格桨心/残弧拟合形状初始化共享平面参考。随后用同一五圆模型的当前
仿射状态，把事件拉回参考平面；各桨使用固定初始坐标轴，因此椭圆主轴的正负翻转
不会逐帧改变相位参考。只测当前结构实际支持的模型槽，不从隐藏桨心补周期。
轴线退化或共享平面过旧/病态时，拒绝空间相位输出，原来的侧视周期逻辑仍负责该情况。

对归一化桨盘事件形成角度theta和径向权重w，按ON/OFF分别累计复数矩
`z = sum(w * exp(2j*theta))`，在100us时间箱、160ms滚动窗口中做复数FFT。
两叶片假设下，这估计的是桨叶相位频率。门槛为相位集中度>=.5、峰噪比>=8、
当前至少9个方位扇区；这些是借用既有相位/周期诊断的固定机制条件，不由位置标签调参。
另要求正反频率能量至少3:1，拒绝“静态空间图案随照明共同闪烁”的对称频谱。
这是明确的实验判据，不是已校准置信度。
固定选择25%原生像素，所选像素的全部时间事件保留；不是无损处理全部事件。

这不把事件数直接换成推力，也不宣称机械RPM已验证。160ms窗口可能滞后，
曲线平滑不证明变向响应更快。

## 实际证据

* 合成100Hz桨叶相位估计99.977Hz；随机时序拒绝、隐藏槽不补值、扁平轴线不做平面反解。
* 机体中心固定、共同平面周期摆动的合成图像，四路仍约99.977–99.980Hz。
  这是几何解耦检查，不是力学悬停平衡证明。
* 非均匀静态圆环共同闪烁、某一亮区占主导的反例：旧峰噪/集中度/扇区门槛误接纳4路，
  加正反频谱能量判据后0路；同两秒真实RAW的47个合格结果保留，没有用降低召回来凑反例通过。
* 相同两秒自采RAW与已冻结的因果五圆观测，60时刻中6次四路相位同时合格，
  共47个当前逐桨频率；与匹配模型槽的SDK像素周期全部处于同倍频的10%范围内，
  平均相对差1.10%。两者来自同一事件源，不是独立RPM真值，因此不能称1.10%真实转速误差。
* 单线程数值环境不同运行的组件均值9.81/16.77ms，加入方向判据后一次16.11ms、P9546.95ms，明显受运行负载影响；
  不属于完整RAW端到端FPS。移除逐事件四项排序后，60时刻除耗时字段外输出逐项相同；
  48k事件×15交替微测，排序中位3.389→两最小值2.069ms。不能将微测速度当整条系统速度。
* 现有作者核心的严格完整椭圆接口在这里零初始化；允许合格残弧初始化的并发调用有一次
  access violation，独立进程中保存了13行后退出。串行小试完成、5次四路合格但均344ms；
  四分之一像素且关闭重复姿态求解后均87ms/2次四路合格，均未接入默认预测。
  串行通过只支持并发隔离有帮助，尚未定位本地崩溃的确切根因。

这些是模块可行性证据，不是论文公平复现成绩，也没有证明新周期输入改善未来位置。
报告位于 `../output/shared_angular_phase_20261027/index.html`（相对项目根）。

## 复现与范围

```text
python tools/check_shared_phase_fft.py <新的输出文件夹>
python tools/probe_shared_phase_fft.py <已有因果RAW运行文件夹> <新的输出文件夹>
```

探针从原RAW重新读事件；上游位置/几何来自已完成的当前观测，不使用人工标签或未来框。
它是模块回放，不能写成“新版本完整raw-only端到端实验”。作者DLL/C++原始仓库均未复制进新模块。

相位测量原理参照 [HelixTrack](https://arxiv.org/abs/2603.09235)，共享投影几何参照
[CoHelix](https://arxiv.org/abs/2610.31384)；批量矩与FFT为本地实验实现，不宣称这类通用原理首创。

下一步优先做可见槽数量变化时的逐桨基准归一化，避免三桨可见集合改变就虚构总推力跳变；
这是低成本、直接作用于物理分支的改进。空间相位还需证明预测价值，再决定是否用异步/GPU加速。
