# 可见性改变时的周期代理归一化

旧输入使用当前有效频率平方的平均值。四台转速不同但恒定的电机，因遮挡改变可见集合，也会改变这个均值。

新增 `visibility_period.py`：先将真正当前合格椭圆/残弧与五圆模型稳定槽关联。四路当前周期连续一致后，记录各槽基准 b_i=f_i0²。
四路可见时计算总平方频率相对变化；部分可见时使用 Σ_visible f_i² / Σ_visible b_i 估计共同倍率，明确依赖共同变化假设，不填隐藏电机频率。
关联含距离、近邻歧义、当前观测、形状及几何epoch门槛。轴线与暂存模型点不能作为电机身份。

合成恒速不等速4→3→2→4：旧代理最大假相对变化24.618%，新模型槽代理为0；真实共同频率变化1.02倍时保留平方变化1.0404。单独隐藏电机变化不可观测，已明确保留。

实际冻结输入60清晰/90侧视时刻：旧控制预测逐项复现差0。模型槽专用修改在清晰段改变预测最大0.308px，无对应独立标签；侧视没有模型槽，输出与原控制逐项相同，13个0.4s目标仍52.718px。
额外将侧视强制改为整机混合周期的独立分支，0.4s均值变为53.910px，P95略好；故该独立侧视改变没有混入模型槽修复。

RAW接线：新开关1.2秒36时刻完成，32当前整机观测、28有效预测、15四桨/2三桨/5两点；不读标签。当前本机短测平均计算能力16.258FPS，成功整机观测13.975Hz，不是30FPS。不能把与此前不同负载/异步观测的短测差别直接归因于约0.06ms的选择器。

使用：

```text
python core/run_fast_structure.py --raw data/event.raw --output outputs/new_run --start 26 --duration 1.2 --async-nn --paced --visibility-period
```

`--visibility-period`启用模型槽修复，未建模侧视仍保留原路径。
`--pooled-axis-period`是未采用的独立混合周期实验。两开关互斥；不加开关仍为旧算法。
