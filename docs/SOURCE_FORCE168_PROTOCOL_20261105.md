# 阶段168：连续局部桨叶输入与创新驱动未知力

在新评分前固定。主线仍为桨叶检测/几何可见性/二力模型；NN只提供冻结观测，不改NN、不混旧NN预测。保留167全部结果及旧默认。

## 直接针对的机制

1. 复用local_pixel_phase每帧已检验的局部区域与竞争频率、scipy匈牙利关联。区域在机体相对网格中续接，最多允许1.5个64px网格的位移；频率用旧bank的log(4/3)-.08变化门槛，只选当前已验证候选，不除2伪造缺失基频。候选仍标明谐波未消歧，区域不冒充电机。
2. 不再用每帧获胜频率形成虚假变化：只从至少2个连续当前区域的log频率增量取中位，积分成相对输入。新增/消失区域不贡献阶跃；无足够当前连续区域则撤销当前输入，超过.12s断档新建输入参考。不同真实频率的可见区域可共同支持变化，不要求它们有同一RPM。这个共同变化代理不是四桨总推力。
3. 四/三/部分二桨仍走当前逐槽证据；该局部续接仅替换轴线/无法恢复完整结构时的混合周期。已识别几何不改，不补隐藏频率。
4. 修复每帧d=a_current-k*u_current直接抵消桨叶新输入的问题：保留未知合力状态及协方差，以原有1000px/s²/.35s动力学尺度传播，用带误差的当前净加速度观测做创新更新；可见集合/参考变化只转移分账，真实同源变化先作用。沿用当前曲线加速度标准误；没有记录时使用明确标注的1000px/s²工程先验。未知项允许每帧更新，不强套恒风/恒隐藏力。

## 固定对照

同一观测带运行：167旧输入/旧配平、连续局部输入/旧配平、旧输入/创新未知力、连续局部输入/创新未知力。每类创新模型另有相同资格/状态更新而已知输入数值为0的控制。所有用相同冻结p/v/a，不优化NN；纯桨叶较强状态和另一录像单列。评价沿166/167既有全部固定起点，不删异常，不扫标签参数。

先用默认尺度200检验来源和未知力机制，避免把其效果与放大k混淆；保留可选既有尺度学习对照，若试验需在其评分前另记。检查恒频不同区域主导切换不制造变化、当前缺失不算当前推力、20%真实同源阶跃不被配平吞掉、参考变更不造加速、输入前缀不变。

局部区域来自已保存的64px网格，只有粗位置/当前频率候选，不能声称逐像素/电机身份或真RPM。当前first_harmonic_statistics不足以使相位解缠，不能仅靠连续性宣称解决谐波。保留真实快变/谐波歧义拒绝。

参考已核验原文/作者仓库：[FrequencyCam](https://github.com/ros-event-camera/frequency_cam)、[HelixTrack](https://arxiv.org/abs/2603.09235)、[HASTE](https://github.com/ialzugaray/haste)。复用项目已有组件与候选，用于本次自写局部源续接，不声称复现这些完整方法或首次提出关联/卡尔曼更新。
