# 阶段169：有限收口，建立能单独使用的桨叶证据模块

用户要求让自己的五圆/可见数/二力思路产生价值，不再陷入无止境实验。本批限定两个交付，禁止在测试结果后扫参数或继续增加分支：

1. **拆开当前桨叶证据、整机模型锁定、力学可辨识性。** 当前合格弧段及其周期可独立提供无序可见贡献，不以持久电机编号或完整五圆模板作为前置；隐藏/未测频率仍归未知项。保留当前证据与补点、模型中心与真实COM、频率与RPM/牛顿力的边界。做一个可直接消费现有原生候选的独立API/JSON/可视化交付。
2. **只做一次固定标定—后缀检验。** 复用已保存纯桨叶状态及NN辅助观测，NN不训练不改。比较对齐桨叶特征、零输入、过去0.4s错时序输入。源时刻未来.4s；所有组同p/v/a基线。用标定段人工终点拟合最多一个非负图像响应系数及二维未知偏置，后缀冻结，不以测试标签在线修正。它是低维响应头的监督诊断，不是所有模型的性能上限或无需标定的RAW部署结果，也不保证输入为真RPM。

## 固定数据划分与拟合

- pure_side与NN side：标定标签目标时刻≤112.0s；后缀查询≥112.0s。中间跨界起点不用于拟合，防止未来目标泄漏。
- clear：标定标签目标≤28.3s；后缀查询≥28.3s，共3个标定、3个后缀候选。
- pure_train2与NN train2：标定标签目标≤44.0s；后缀查询≥44.0s，共3个标定和3个后缀候选。
- 所有预定起点沿166/168既有网格/清晰精确终点，不删高误差。原生特征以当前观测带为准；错时序只取过去0.4s，不从未来调换数据。
- 基线为同一当前p/v/a的Singer条件外推。桨叶特征为当前方向/幅值趋势的可见贡献未来增量，未知偏置吸收常值误差；不是把当前推力重复叠到已经估计的净加速度上。
- 6px噪声尺度、未知加速度偏置1000px/s²先验；已知响应使用训练段特征能量确定尺度一致的零均值岭先验，使一个标准差对应6px影响。一次闭式解/非负约束，不网格搜索。只有训练标签可被拟合读取。
- 训练和测试均为旧开发片段，不叫新盲测；人工标定诊断成功也不能宣称无需真值自适应成功。若对齐输入不稳定胜过零/错时序，本版本停止扩大“转速反推推力能提精度”的主张，不继续在这些点上调系数。

## 模块范围

当前区域数是桨叶假设，不能保证等于物理电机数。四个频率均合格可求无序平方和；三/二个实测贡献不补隐藏转速；侧线仍独立处理。几何三点补第四点要求已确认模板，二点不虚构完整3D姿态。现有模型并未因此被替换为NN。

旧用户A—F六帧只作可见性参考（A三、C四、BDF近线、E重叠），不是COM/RPM或相邻33ms窗的真值。仅用真实数据图和受控缺测机制说明API，不将合成/删点试验包装成真实遮挡检测精度。

收口术语更正：早稿的“监督上限”并非数学上限，现改为“低维响应头监督诊断”。数据划分、拟合、预定通过条件及已落盘预测未改，不追加试验。
