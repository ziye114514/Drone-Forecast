## 已落地、值得保留的改动

`inverse_normal_response.py`：从过去原生位移对组成切向加速度样本，复用289中

`a(t) = A(t) n(t) + b - beta v(t)`

的切向投影消去包括隐藏桨在内、可任意变化的 A(t)。先检验外部偏置两维是否有数据秩，再估计 b/beta 的联合不确定度（包含二者相关项，不给 b 人工零均值先验）。仅用可观测信息校准**未来**法向响应幅值。当前p/v/a、可见贡献、隐藏力所有权不改；b不是已测重力/风，A不是已测总推力。法线统一原观察器图像向上符号先验，正负翻转不能改变校准资格。

`physical_publication.py`：显式新标签 `drag_filtered_normal_derivative` 才使用新核。若 beta 表示阻力响应，短时A不变时应有 `a_dot=-beta*a+A*n_dot`，不能把旋转力和净加速度衰减直接相乘。新核支持常角速和既有Singer角加速度。默认旧路径数值不变。

`run_rotor_only.py` 新增 `--rotor-inverse-normal-response`，仅支持当前native relative/fixed/plane-adaptive配置，默认关闭；`run_rotor_candidate.py`沿用解析器，可直接在原命令加该参数。可叠加旧 `--rotor-tangential-memory`，共用切向样本，不按录像自动选版。当前不建议默认叠加torque来宣称新收益。
