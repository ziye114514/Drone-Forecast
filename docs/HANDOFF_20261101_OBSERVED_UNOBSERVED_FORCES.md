## 用户定义，优先于此前方案

> 二力模型是可测力＋不可测力，隐藏的桨叶推力属于不可测力，计入那里面。

因此：

`m*a = F_observed + F_unobserved`

`F_observed = 当前观测足以支持的桨叶推力贡献`

`F_unobserved = 隐藏/不可靠桨叶推力 + 重力 + 风/空气阻力 + 其他未建模作用`

当前程序采用的是图像有效模型：`a_img = k*u_observed + d`，单位px/s²。k*u_observed仍是事件周期与投影方向提供的有效代理，不是已标定牛顿力；d包含未观测桨力及其余未知作用。不能将d直接命名为风力。

**不需要先补齐四桨推力才能预测。**几何可以补隐藏桨的位置，但隐藏推力由未知项状态承担；不虚构隐藏RPM，也不以四桨齐全作为部分/侧视预测的硬前置。

## 保持检测主线

RAW原生ON/OFF过滤桨叶 → 五圆共享几何 → 四桨/三桨/二桨或侧视观测分工 → 可测代理＋不可测状态 → 二维预测。

|当前证据|可测项|不可测项及结构先验|
|---|---|---|
|四桨均有可靠周期|四份当前贡献|重力、风、阻力及其他未知作用|
|三桨可靠|三份当前贡献|第四桨力等归d；几何上可补第四点，不补实测周期|
|二桨/侧视|当前可靠周期、投影信息支持的贡献或变化代理|其余桨力归d，不要求恢复完整四桨|
|混合周期无法分离旋转源|明确标为混合代理及其资格|不能乘4充当已测总推力；不可靠幅值由未知状态承担|

五圆提供共享结构和姿态先验，机体中心与平面摆动分开；无需识别机头机尾。不引入G重建或整机NN作为前置，旧NN入口保留为历史对照。

## 当前代码还没完全按此分账，必须改的地方

当前首次初始化仍要求four模式下4路稳定周期；部分可见时把0.12秒内隐藏槽先验加入总平方和，标为partial_individual_short_prior。虽然没有冒称隐藏RPM实测，**这仍不是用户要求的显式分账**，也会阻碍仅三桨/侧视启动。

### 2. run_rotor_only.py

当前直接将period_proxy的u传给联合状态。待改：显式传可测贡献、可见集合/资格、统一尺度基准和集合切换信息；不得因缺完整4路而关闭已有可靠可见信息。几何补点与力输入拆开。

### 3. rotor_force_observer.py

已有联合p/v/d/k及首次输入获取、过期时的分解重锚；尚未完整处理按可见集合变化转移贡献。待改：贡献在可测/不可测两项之间转移时，处理均值和协方差，保持同一机体中心、速度及净加速度分解一致。

同一物理时刻，仅因可见性变化，可测代理由a_obs_old变为a_obs_new时：

`d_new = d_old + a_obs_old - a_obs_new`

这是分解转移，不是新增外力或测到隐藏推力。要同步传播周期、k与未知项的不确定度。**只吸收可见性变化产生的账面跳变；真实转速/法线变化必须仍能驱动加速度，不能每次都重锚将其抵消。**隐藏桨重新可见时也要从d转出对应贡献，避免双重计入。

## 接手后的实施顺序

1. 固定observed/hidden/ambiguous字段、资格和跨可见集合一致的标度，保留阶段161控制与备份。
2. 可测项只算当前可靠贡献，隐藏贡献归d，允许部分观测启动。不用三桨/二桨平均值乘4冒充全桨实测，也不每换数量就把可测项重新归一化成假总推力1。
3. 实现可见集合切换的分解转移与协方差传播。未知项组成会随可见性变化；不能把这种变化都解释成真实风力突变。
4. 做少量有意义的机制用例：转速不变、4→3→2→4时无假加速；可见桨真正变速仍响应；隐藏桨再出现不重复加力；无未来事件/标签参与输入。
5. 用现有同一批观测短回放与固定9查询比较周期增量、总体误差、有效覆盖、切换瞬时加速度，保留小收益与坏例，不大规模扫参。
6. 再推进已有相位/谐波模块及GPU同步、几何成本优化。不要重新把“唯一算出第四桨真实推力”列为继续预测的硬条件。

不可测不等于瞬时已知：隐藏电机真正变速时，只能由截止当前的运动反馈更新d，并保留不确定度。无需先识别质量、桨径、气动系数和风速，目标仍是有效图像预测，而非宣称所有真实参数已唯一辨识。
