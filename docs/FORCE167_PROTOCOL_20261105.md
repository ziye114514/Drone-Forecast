# 阶段167：修复可见桨叶二力外推，而非优化NN

用户强调自己的桨叶检测、可见数量分支与二力模型才是主要研究对象。NN仅作冻结的定位/速度观测辅助；不改NN、不再用其完整预测加门控作为优化目标。纯桨叶输入也单列回放。

本轮在看新评分之前固定如下机制：

- 复用已有当前bank资格、同一原生几何与周期。四/三/部分二桨仅求当前可见贡献；侧视混合只作有效变化代理，隐藏桨力归未知项。
- 修复参考问题：可见性转移用于当前已知/未知分账；未来法线旋转必须作用于当前可见的非零幅值，不能旋转已经减去参考而接近零的变化量。侧视单个混合代理不乘4、不叫总推力。
- 复用NormalTurnForecast与ThrustTrendForecast相同窗口(.35s)、6样本/.16s、.12s断档、2%频率噪声底、未来0.4s幅值最多1.25/0.8、方向最多30度；按当前可见源分别维护幅值历史，不接受缺桨的臆造频率。
- 未来加速度采用锚定增量：a(s)=a_current exp(-s/.35)+k sum[A_i (exp((r_i+j*w)*s)-1)n_current]。未知基线承担抵消当前可见贡献的项，不让它随桨盘转动。稳态平衡、可见数切换均不得凭空加速。
- 复用flow_identifiable_gain.fit_gain：v=v0+k∫u dt+d*t，先消掉初速/常值未知项，再辨识k；不要求“当前净加速度已经合格”才尝试。仅在同一连续可见来源段内用已观测NN/KLT速度及其协方差。混合输入的正拟合只解释为有效图像响应，不是真实机械/推力系数。拟合失败保持默认200，不能扫标签放大。
- 相同输入做zero（无桨叶趋势）、normal_only、full_fixed、full_learned；另列旧完整入口。断掉周期或只改变参考时不应有假的预测提升。默认入口不升。
- 使用166三段及固定全部查询，不删异常；源时刻+0.4s，人工标签只在全部回放落盘后评分。纯桨叶侧视/另一录像沿165原固定查询单列，不借NN分数声称纯桨叶成功。本轮无整线FPS证明。

方法借鉴而非新造已有数学：仓库flow_identifiable_gain.py / NormalTurnForecast / ThrustTrendForecast；增量力学参考Smeur等的[INDI原论文](https://arxiv.org/abs/1701.07254)与[作者论文](https://www.ezratal.net/files/CDC18_1876.pdf)，这里是外部图像预测，不是飞控复现，未复制作者代码。

## 首轮诊断后的单次改进（新评分前固定）

首轮已执行：NN辅助侧视29次、清晰14次进入可辨识解算，但全部不足2倍标准误；纯侧视旧保存记录缺dt字段，不能直接当作没有运动。后续slow_gain不改NN：有效尺度学习改用原慢增益已有的最多3s连续来源历史，姿态/转速趋势仍.35s；同样检查常未知项残差、2sigma与原上限，不按位置标签选窗。纯桨叶记录仅在相邻两帧均有当前匹配、且中心位移与保存dx/dy在1e-6px内完全一致时恢复dt，禁止跨失锁或参考变化臆测时间。旧final首轮保留；最早根目录因numpy计数JSON序列化中止的尝试不评分。

slow_gain暴露覆盖暖启动问题：段首速度的midpoint早于第一个当前输入，导致一条不覆盖的速度行否决整段，长窗更久无法进入解算。covered_gain只剔除时间不在已知输入覆盖内的速度，不补缺失输入、不跨来源重启；其余数据/门槛不改。该修复由时间审计决定，不按标签选取速度行。

covered_gain发现另一个实现缺陷：部分正拟合已超过2sigma，但被固定k<5000拦住；k依赖输入归一化单位，任意改单位就改变接受资格是不合理的。scale_gain复用FastForceResponse已有的3000px/s²/观测输入激励RMS上界，保留正值/2sigma/残差资格，不按标签选择增益。fit_gain新增可选maximum_gain参数，旧调用默认5000不变；仅新候选使用尺度一致上界。未知基线允许抵消较大已知力，不能按绝对k限制正常平衡。新结果单独保存，不改旧covered_gain记录。

source_gain在scale_gain评分前进一步限定来源：已识别可见和、全局池化、局部一阶模板分别保留有效增益，禁止将一类混合代理的系数直接用在另一类代理上；暂无估计的来源沿默认200。当前净加速度由未知项配平不变。此项由输入单位/含义差异决定，非按终点误差挑选分支。

最后复查发现较强纯桨叶relative观测器原声明是2px位移噪声，不能把两份6px绝对位置噪声强加给它的速度回归。pure_best_side_2px另列修正此处的一致性，未从标签选择噪声，也未声称2px经真实传感器标定。其他纯桨叶旧绝对观测仍原先验，原pure_best_side对照保存。预测/资格若无变化不包装成精度提升。
