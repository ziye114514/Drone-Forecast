## 2. 必须区分的事实和研究假设

- 用户的研究假设：桨叶高速周期运动可提供突出于背景的事件特征，经过合适滤波可以主要显示桨叶。
- 尚未证明：任何场景都能只靠某个事件数阈值把桨叶唯一分离。高事件密度不等于高转速；频率峰也可能来自周期照明或其他运动物体。
- 因此先测试密度抑制作为快速候选筛选，再用时间戳、极性、周期一致性和空间支持确认。不要把阈值后剩余亮点直接命名为桨叶真值。
- 不能通过丢弃时间戳/极性、8bit 计数饱和后再宣称恢复了可靠 RPM。显示图与周期估计保留不同的数据用途。
- FRED 整架目标约几十像素不代表桨叶信号绝对不可检测；也不代表足以分辨四个桨盘。是否能定位目标、是否能分桨、是否能估计周期必须分别记录。

## 5. 接手后按顺序做什么

### A. 先建立不依赖整机检测框的桨叶支持图

1. 选自采清晰桨盘、三桨/重叠、侧视各一小段，以及一段空场/背景干扰。先复核已有片段和缓存，优先用用户 E:\dataset；FRED作小目标补充。
2. 从原生(x,y,t,p)事件生成无G重建的ON/OFF展示。用已有去噪与密度统计快速排除孤立事件，保留滤波前图、密度筛选图和周期确认图三种结果。
3. 初始全视野粗搜索或分块搜索，不读真值裁剪，不依赖整机NN框。发现候选后局部细处理，失锁允许重新全局发现；不要让错误ROI永久挡住真实桨叶。
4. 复用逐像素周期/谐波和后续子窗检验，处理相邻像素支持、谐波/半频歧义和公共闪烁。结合已有native_event_alignment，检查桨叶区域移动造成的像素停留时间不足；有合格过去位移时再做因果运动补偿，无速度时保留短窗发现，不以未来速度或真值对齐。周期支持引导原生弧段而非硬裁成新轮廓；参数只在开发片段决定，不按评分目标位置修阈值。
5. 输出桨叶支持像素、弧段、可能桨盘区域及资格/时间年龄；单独输出覆盖这些区域的bbox。可见性证据不足时只报告“桨叶候选区域”，不要强称4/3/2桨。

首个交付物应是短小可运行的独立桨叶前端及原始/密度/周期三联图。先看它有没有保住真实桨叶、滤掉哪些背景，再决定是否训练模型；不要继续把主要算力用在整机框尺寸拟合上。

### B. 再接回用户的4/3/2桨可见性分工

- **四桨可分**：由当前原弧拟合椭圆并计算桨心，建立共享平面五圆模型；用合格周期提供逐桨相对转速/有效推力输入。不要求识别机头机尾。
- **三桨可分**：在已建立或可验证的结构约束下推断缺失第四桨，携带不确定性。单帧三个点不是无条件唯一补全；缺失桨的位置推断不等于测到该桨转速/推力。
- **侧视/两组可见**：不要求恢复四个椭圆或先凑五圆模型；从桨叶支持线/局部弧求投影轴及法线候选，用合格周期池化作为有效推力代理。区分两个可见桨和两组重叠投影，不能由两点无条件唯一恢复3D平面或四桨总推力。
- **0/1组或不确定**：明确不可判定或短时低置信续推，保持重新发现；不能因预设“一桨不会出现”强凑数量。跨分支平滑权重根据当前证据和不确定性变化，不把缓存补点当当前观测。

桨叶框中心/几何包围盒中心不必等于机体中心。可见桨数变化时，沿用共享结构的中心估计及其不确定性；未建模时输出“桨叶区域位置”，不要把遮挡引起的bbox中心变化直接当平移。

### C. 周期变成有效推力，再检验预测是否获益

- 在未知质量/桨径/桨型和无同步日志条件下，先称“相对周期/有效推力代理”，不声称得到真实牛顿推力。事件数不能直接替代转速。
- 沿用用户v3二力思路：可观测桨叶输入 + 重力/风/相对空气运动阻力等的合并未知净作用；由已到期位置残差更新像素域有效参数，严格因果。
- 可见数量变化会改变事件能量，不能把“少看见一个桨”直接当总推力下降；两三桨不以隐藏桨均值冒充观测。保留上一时刻的合格推力代理和变化率，但只有证据支持时才推进。
- 最后在同检测位置/同查询时刻比较周期/姿态输入打开与关闭，目标固定为实际输出后0.4秒；同时报告缺失与延迟。只有这一步改善，才能说桨叶检测提升转化成物理预测提升。
