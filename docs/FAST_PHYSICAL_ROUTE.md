# 五圆物理主线与30FPS目标

用户选定研究主线：五圆与可见性切换 → 当前姿态/周期 → 有效推力加速度 + 总扰动 → 下一位置。

## 当前入口

```text
python core/forecast_mainline.py structure-fast --raw <event.raw> --output <新目录> --start 110 --duration 3 --async-nn --paced --verify-frames
```

默认**不运行传统加速度拟合、尺度外推或传统预测输出**。当前位置/速度的最小滤波仍保留，作为力学积分初始条件。原v7代码、旧结果保留，传统对照在保存当前预测后离线重建；它不占用这条实时循环。

## 结构与力学

* 原生事件时间不变。30Hz源切片为33333µs；结构只看每个截止点之前20ms，频率算法使用所选像素的全部原始事件时间。SDK要求起点整除切片，实际起点写入protocol。
* ROI先分别邻域平滑ON/OFF再取min，沿用阈值4、开闭运算、已有椭圆/残弧验证与凹曲率拆分。当前合格弧可反推桨心，隐藏点不会变成观测。四桨联合建模，三桨只使用近期模型完成，退化桨盘提供无向轴。
* `axis_only`只表示整机计数支持一个轴，**不等于已确认二桨侧视**。机体扁长不能抢先覆盖当前四桨证据。姿态使用二维弱投影和图像向上符号先验。
* 四个当前有效频率使用平方均值，与总和只差可吸收的常数4；部分可见时明确记录隐藏转速的代表均值假设。整机池化频率不对应四个已识别电机。
* `a_img = k u_current + d_slow`，`u = relative_f² × n_img`。`k`是像素加速度增益，`d`是总图像扰动，不是可分别辨识的质量/桨叶尺寸/风力。不是测得的牛顿推力。
* 0.2s已到期位移残差监督慢参数；先把输入去均值再估增益/截距，输入激励不足则冻结。当前合格输入立即使用，不等待本次未来位置到期。第一次/长时间失锁后将未知扰动与默认增益对齐，避免突然凭空加速。

## 速度措施

* NN异步约10Hz初始化/复锁；间隔帧用当前ON/OFF图像KLT平移。迟到NN保留其观测时间，通过已测当前平移对齐，未将旧框当当前NN检测。
* 仅保留一个结构前端；凹曲率重建2Hz，当前几何/轴线与物理状态30Hz尝试更新。
* 固定25%像素周期采样复用已有SDKFixedPixelAxis；保留所选像素全部时间事件，不做时间降采样，不合成频率。
* ROI筛选改用已安装SDK的C++实现，20ms时间后缀用视图；边界/计数与原NumPy选择逐项一致。
* 双共享内存槽独立解码进程，FIFO、不跳源帧；避免SDK解码线程和主线程争用GIL。
* `--reuse-conic-uncertainty`是实验选项，默认关闭。短试未证实速度收益；不把协方差近似当当前完整分解。

## 如何判断30FPS

分别记录源切片率、含解码等待/日志的服务时间、真实新图像观测率、完成滞后和33.3ms内比例。播放视频的30FPS不能用于达标。冷启动/RAW随机定位另外记录。当前各小段是否达标以本轮报告为准；没有宣称稳定30FPS或变向优于基线。
