# 因果边界与滚动0.4秒预测（2026-11-10，用户最新要求）

优化目标是：当前可见桨叶持续进入观测；机动出现可观测证据后，及时更新下一份从新时刻起算的0.4秒位置预测。

## 预测发出后的机动

- t时刻的预测目标为t+0.4，发出后冻结并保留原始结果。
- 对t之后才发生、在t时刻没有可观测先兆的操纵变化，不要求算法提前知道，不为事后大误差强行拟合或新增预测规则。
- 新观测在t+Δt到达后，用新观测更新状态，重新预测t+Δt+0.4，不等待上一份预测的0.4秒结束。
- 不用未来画面修改过去预测，不因误差大就倒推出“这一点不可预测”。机动起点/可观测先兆没有独立真值时保留不确定性。
- 历史同102起点FDE继续原样报告，不删除机动点来宣称35/30px达标；同时另报观测断档和机动后更新响应，避免只拿旧预测惩罚未来新操纵。

## 分开处理的实际缺口

1. 可见桨叶没有被当前周期/支撑链接收：属于检测入口问题，优先修复。
2. 当前机动证据已经进入观测，但状态/新预测迟迟不更新：属于响应迟滞，需要修复。
3. 旧预测发出后才出现新的机动：记录旧预测误差，但不作为“必须提前猜中”的检测缺陷。
4. 原生信息确实暂时不足：明确短时模型外推及其年龄，不把历史模板当新测量，不补隐藏RPM。

## 下一步实施边界

优先恢复已有目标的当前证据，区分“确认当前有桨叶”“获得合格位移”“获得可用频率/力输入”。保留首次发现的严格门槛；续踪必须有当前原生支撑与周期关联，不能仅靠旧框/惯性宣告新检测。续踪不能自动授权新的逐桨RPM或推力测量。

已有388/405续接原型能补这个包，但全局精度曾退化，不能不加分工直接默认开启，也不把整体降阈值当新方案。需要查清新增支撑/位移/几何参考各自的可靠性，再连接状态更新。

验收除原始完整FDE外，应加入：当前可见而漏接的连续包数、最近真实观测年龄、机动证据到状态修正的延迟、到新0.4秒预测修正的延迟，以及错误复锁。源时间包间隔不等于墙钟FPS，不预告实时达标。
