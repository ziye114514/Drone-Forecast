# 变向响应目标澄清（2026-10-26）

用户要求：无人机开始变向后，相比普通位置/速度外推更快、更准确修正未来位置，减少滞后和过冲。不是要求在尚无任何变化时预知意图。预测应随连续速度与加速度自然变化，不能用显示插值冒充改善。

## 评价目标

- 变向起点附近响应延迟：何时开始做与真实机动一致的预测修正。
- 开始变向后0–0.5/1秒的0.1/0.2/0.4秒同起点预测误差。
- 过冲、虚假反向、平稳段误报，以及输出年龄/缺失。
- 比较纯位置速度外推和当前v7；整段均误差仅作补充。

减速向右时，速度可以暂时仍向左；正确预测先减少左向外推，再随速度过零移到右侧，不能强行立刻把下一位置移到右边。

## 学习有效动力学的建议（计划，尚未实现）

二维近似采用`a_img = k * q * n_img + d`：q是周期强度代理，n_img是有资格的方向代理，k是有效图像增益，d是总扰动。k不是独立质量或推力系数，d不是真实风力读数。

参数学习与快速状态更新分开：

1. 使用默认k和较大不确定性起步；用过去已经到期的可靠位移残差校准。
2. 在倾斜/周期存在足够变化时估计有效增益；匀速/悬停、投影退化或特征恒定时冻结不可辨识的增益。
3. 增益较慢适应，扰动避免与推力变化同时任意快速变化，否则二者互相吸收；需要单独检测定位跳变。
4. 参数获得可信度后，当前可信姿态/周期变化立即进入运动更新，不等待本次未来误差到期。
5. 在增益不可信时，可以先以机动证据调整滤波过程噪声和分支置信度，保留运动学回退；此类机制有既有论文，不能称首创。

当前DelayedResidualDisturbance使用已到期0.2s参数更新，并要求累计更新/同预测时域损失各至少10次才获得融合权重。因此目前主要是慢速校准/修正原型，不是已实现的快速机动触发器。

## HZ与硬件

当前观察：轻量v7短段整步中位约37.65ms，发布约5Hz但18/20有效；完整结构研究链约168–181ms/源帧，NN约29–31ms，几何/桨盘分支占较多CPU时间。两种负载不同，不作严格速度倍率比较。

优先工程安排（待实测）：位置/低成本轴线较快更新，完整四桨重建较慢且异步，保留原生事件时间戳用于周期估计；使用最新数据而非完整FIFO积压。平稳低频发布，机动证据可靠时可触发额外发布。5Hz固定发布最多带来约200ms的发布等待，不能只用FPS衡量响应。

先测变向反应与端到端观测年龄，再判断是否需要升级CPU/GPU；目前没有要求用户购买设备。

方法参考：[RPM调制Kalman过程噪声](https://arxiv.org/html/2603.01997v1)、[桨盘方向与推力驱动状态估计](https://arxiv.org/html/2604.18289v1)。本文件记录目标与方案，不代表这些新策略已实现或已验证收益。
