# 阶段166：NN定位固定，检验桨叶结构与二力预测增益

用户2026-11-05授权：桨叶整套逻辑、可见数量切换及二力模型是研究重点；允许帮助现有NN系统，保留纯桨叶入口。这里NN负责定位，未训练神经轨迹预测网络。不能把一般NN＋物理融合本身当首次创新。

## 预先固定的实验

复用现有NN/KLT当前观测，不重训、不改变NN请求时序。原始事件只为新增桨叶特征提供输入，任何预测分支不反向改变之后的检测或特征。坐标标签只用于推理完成后的评分。

四组使用相同NN观测、原始事件截止时刻、滤波骨干、默认噪声、初始化、预测积分与评分查询：

1. `NN_motion`：NN/KLT位置＋既有联合位置/速度/净加速度状态，无外部桨叶输入。
2. `NN_geometry`：加已有QualifiedCenter五圆/合格部分结构中心融合；保留协方差交集和原门槛，无外部周期力。
3. `NN_four_force`：同2，仅当四槽都得到当前合格周期支持时采用可测贡献；其他情况归未知合力。
4. `NN_visible_force`：同2，四/三/部分二桨和轴线退化按当前证据进入可测项；隐藏桨力、重力、风阻等归未知d，不补缺桨RPM。

另列保存的旧入口原预测，避免只赢一个较弱的新基线就声称胜过旧系统。全部默认值沿用，位置标准差6px（方差36px²）、tau=.35s、k=200像素动力学尺度；不按录像调参。k不是真实推力标定。几何融合时沿用该模块的协方差代理，不把新增图像证据当独立噪声。四组复用同一已有合格当前光流观测，按其midpoint时间写测量矩阵；NN/KLT位置与光流共用图像，采用2倍块对角噪声上界，不假装相互独立。

## 输出与解释边界

原生特征/几何只提取一次，保存不含坐标标签的观测带，再跑四个滤波分支。报告均值、中位、P95、全部预定起点的可用数、每点成对差异、4/3/2/轴模式与周期实际使用数。旧NN网络输出不变，收益属于预测系统而非检测AP提升。

第一轮是固定输入、源时刻+0.4s的开发消融，不能冒充完整RAW+NN+桨叶实时30FPS。若增益明确，再接真实流水线测新增耗时与实际发布误差。无增益照报，不扫这些标签选参数。

文献：RPM调制KF已有 https://arxiv.org/abs/2603.01997 ，原文方法使用标注框/位置来隔离检测影响；共享四桨几何已有CoHelix https://arxiv.org/abs/2610.31384 。本试验关注当前自写可见性分支、可测/未知分账与NN实际输入的增量，不宣称完整复现作者方法。

## 后续增量方案（第一轮与直接替换失败后，在新评分前固定）

第一轮新联合状态骨干比旧NN入口弱；直接保持旧p/v而替换力输入仍退化。两轮结果全部保留，不将弱基线上小收益冒充超过旧系统。

后续固定旧入口所有p/v、有效性与原预测，只增量接入native_pose、native_four、native_visible三个候选。native_pose关闭周期力但保留同一原生几何，native_four只用当前四桨周期，native_visible允许当前部分/侧视贡献。沿用AdaptiveForceMemory的已到期自身观测、6px Huber、36px²零权重岭先验、.35s衰减、3s历史、.199s起点间隔。只用0.4s到期目标学习0到1权重；无当前资格则不加修正；参考重锚清空学习。未到期数据绝不使用，人工标签不进回放。三分支同规则、同查询、无标签调参；各输入前缀须保持输出不变。这里是在线候选可信度学习，不是已标定真实推力。

增量结果后加一个归因控制，在它的评分之前固定：`native_evidence_only`保留完整方案完全相同的当前周期/姿态资格与缺失时序，仍允许未知合力学习和原力记忆，但把已知输入数值置零。用于判断改善来自实际周期/方向的数值，还是仅把周期当作允许未知项更新的开关；不能只比较一个同时禁用了未知项更新的“关周期”就宣称周期推力有效。
