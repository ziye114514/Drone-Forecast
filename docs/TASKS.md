这些不是泛泛的方向，是**边界清楚、有明确终点**的小任务。想参与的人挑一个，
不用先读完整本 `WORKLOG.md`。

数据与权重可以按需提供（RAW 不在仓库里，见 `MODELS.md` 与 `.gitignore`）。
不需要数据的那几个标了 `无数据`。

## 不需要 RAW / 权重 / GPU（新人的第一个活）

### 1. `无数据` 把评分器做成单测

`research/stage144/score_dense.py` 现在只能手工跑。它有几个容易踩的口径问题
（人工真值 vs 稀疏端点、missing 怎么报、`--compare-key` 的同起点配对）。
给它写一组不依赖真实数据的单测：造一份假的 `labels.json` 和假的预测，
断言分数算得对、missing 如实报、两个口径不会混。

**终点**：`python -m unittest discover -s tests` 能跑到这些新测试，全绿。
**为什么值**：这是最容易被后人改坏的地方，改坏了所有历史数字都失真。

### 2. `无数据` 扩充平铺名检查的覆盖面

`tools/check_flat_names.py` 现在覆盖 7 个列表共 280 项，判据是「`for VAR in CAPS:`
循环里出现 `ROOT/VAR`」。搬家时这么坏的至少有 6 个文件，可能还有没发现的。

**终点**：扫描 `core/` 与 `tools/` 下所有模块，找出仍在用 `ROOT/裸名` 读文件
但没在上面这张表里的地方，加进去；如果是真 bug 就修。

### 3. `无数据` 给 340 个模块生成一张索引

现在没人知道 `core/` 里哪个文件是干什么的。用一个脚本从每个模块的
docstring 首行 + `__main__` 有无 + argparse 的 `--help` 抽取，生成
`docs/CORE_INDEX.md`：文件名、一句话说明、是不是入口。

**终点**：`docs/CORE_INDEX.md` 生成出来，README 链过去。
**注意**：76 个有 `__main__`，其余是库模块，跑 `--help` 会失败——这是正常的，索引里要区分开。

## 需要数据，但不需要改算法

### 4. 复现基准数字

用 `research/stage144/score_dense.py` 复现人工标注口径的 50.03 px（train6 侧视）
与 59.30 px（train2）。两份标注在 `output/dense_labels_side_110_1195` 与
`output/dense_labels_train2_40_46`（不在 git 里，需要单独给）。

**终点**：你能得到一样的数，或者明确指出差异出在哪一步。
**为什么值**：这一步做完，你就理解了整条链；而且如果复现不出来，那是更重要的发现。

### 5. 把侧视段的谐波歧义查清楚

同一 tick 上 34.4% 的时刻会分出两个频率族（清晰段只有 3.4%）。现有两种解释：
真的有两个桨转速不同，或者频率估计本身在噪声里跳。

**终点**：给出一个能区分这两种解释的判据，并在数据上跑出结果。
**现状**：`research/stage13` 有当时的分析，`research/stage143` 有局部多频的观测层结论
（29 条轨迹、log 标准差 0.04、同时刻离散中位 1.165）。

## 需要改算法（难，但方向明确）

### 6. 跨录像泛化

现在 FRED 系列新录像上 0/25 有效输出。train2（跨录像留出）能到 59.30 px，
但换到 FRED 就完全失效。是特征分布问题、还是几何假设不成立，没有查过。

**终点**：说清楚 FRED 上为什么失败（哪一步先崩），不需要修好。

### 7. 30 FPS

实测中位 73.8 ms/帧（约 13.5 FPS），清晰段更慢（109 ms）。
其中 geometry 46.4 ms、前端 42.5 ms、GPU 11.2 ms、模型 0.33 ms。
清晰段的结构拟合单独占 35 ms。

**终点**：定位到能砍掉 20 ms 的具体位置，并实测验证。不要凭感觉优化。

## 已经证伪，别再试（除非你发现了新证据）

| 方案 | 为什么失败 |
|---|---|
| 速度守门（鲁棒斜率 + 150 px/s 分歧门） | 稀疏端点好看，人工真值全输；train1 硬加速段 84→327 翻车 |
| 四路物理修正（线法向 / 线方向 / veto） | 全部比 baseline 差 0.4–2.7 px；加速度主要在**沿线**方向，投影到法向是用错轴 |
| 平移/摆动分离 | 侧视 50.03→50.78~70.64，全退化 |
| 自适应阻尼（按 \|a\| 分组） | 最优 α 无单调关系（低 0.9 / 中 1.3 / 高 0.5） |
| CTRV / IMM | 0.1–0.4 s 无收益；拉到 1.0 s 才反转 |
| 按位置的长记忆桨叶关联 | 错误率 1.99%→7.05% |
| 加速度标度调参 | 各窗口最优值 1.0/0.25/0.6，无统一值 |
