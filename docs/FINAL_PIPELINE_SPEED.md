# 完整流水线计算优化（2026-10-27）

目标是让原生RAW → 整机观测 → 五圆几何 → 周期代理 → 二力模型预测真正变快。没有降低输入更新率、几何窗口、采样点数或资格阈值，也没有把播放帧率当处理速度。

## 已接入的改动

`run_fast_structure.py`默认启用等价计算优化，`--reference-compute`保留原计算路径。原始位置核心与已发布ZIP不改。

1. 拆分粘连轮廓前，先检查每一组子弧都必须满足的同一个父轮廓残差条件；父条件不成立，直接结束。第一条弧失败时，不再拟合必定无用的另一条弧。有效拆分的随机样本、验证条件和返回几何保持原样。
2. 重用已经算过的弧残差；细线宽度的5/95分位计算改为等价线性插值，避免通用分派。保留原函数作对照。
3. KLT每帧只需事件占用灰度，直接生成该灰度；只有真正请求神经检测或预览时才生成原生彩色帧。传给神经网络的图像不变。
4. 有界双槽RAW预取提前启动，与GPU模型初始化重叠；不丢源帧。首次结果耗时与稳态处理能力分开记录。

另保留可选`--prefilter-decode`：在解码子进程按原顺序运行同一SDK降噪器，以另外两个固定共享缓冲把过滤后的事件交给主进程；几何仍使用原事件。该功能降低主线程串行耗时，但首次侧视同步对照的平均FPS未进一步改善，暂不默认。它不会少算事件，生产者耗时和消费者等待都保留。

## 端到端结果

使用同一RAW、同一模型哈希、30Hz源时刻、同一20ms几何窗、相同10Hz神经检测调度。同步NN用于固定观测输入；计时不启用profiler或预览，包含RAW等待、输出写入。侧视先旧后新，清晰段反序，避免只用一种运行顺序。

| 2秒RAW片段，60个源时刻 | 原计算平均处理能力 | 等价优化 | 每帧服务耗时中位数，原→新 |
|---|---:|---:|---:|
| train6 110–112s侧视 | 13.71 FPS | 17.57 FPS | 56.27→43.43ms |
| train6 26–28s清晰 | 14.78 FPS | 22.19 FPS | 56.41→45.45ms |

这是当前机器的短片段结果，系统调度、GPU和写盘有抖动；百分比不是跨设备稳定加速保证。两段合计120个时刻的整机框、几何、周期、模型状态与预测逐项相同。清晰段保留18个four、3个three、5个partial_two；未把侧视硬凑成四桨。

侧视20个既有人工锚点中19个有当前观测，中心误差中位5.92px、IoU中位0.624，优化前后相同。0.4s预测在9个既有开发参考目标上平均37.82px，前后相同。该短段不能代表全数据集召回、mAP或新测试集精度，框中心也不是真实物理重心。清晰26–28s没有独立人工框，不能报该段检测精度。

首次侧视结果35.11→19.59s，主要节省来自RAW寻址和模型初始化的重叠，并非每帧推理突然快一倍。`initial_seek_decode_s`只记录消费者阻塞等待；完整启动看`first_result_after_s`。

逐像素预测式谐波分支仍作为实验观测保留，没有直接塞入每帧主流程。其CUDA组件36–61ms尚会挤占主流程预算；目前不能用周期像素增多或单条弧变清晰声称最终精度改善。相关研究记录见`PREDICTIVE_HARMONICS.md`。

可选降噪解码重叠与异步NN组合，在110–114s实际处理120个源时刻，115个当前整机观测、111个有效预测。平均完整处理能力24.77FPS、当前观测输出23.02Hz，每帧服务耗时中位30.49ms、P9591.11ms。全帧保留使积压不能隐藏：完成延迟中位约1.13s，不能称低延迟实时30FPS。异步的NN回包时机不同，该组不属于与同步参考输出等价的120时刻结论。

该4秒段40个开发人工锚点中39个有整机观测，中心误差中位5.81px、IoU中位0.651；但0.4s预测18个参考目标的平均误差73.22px，物理预测仍不准确。该段范围更长，不能直接与上面2秒误差相减，声称新算法改善或恶化。异步NN的调度也不同；需要同目标控制才能比较。

## 使用与对照

```powershell
# 当前等价计算优化；使用本机已配置的SDK Python运行。
python core/run_fast_structure.py --raw E:/dataset/train/6/media/event.raw --start 110 --duration 4 --output ../output/my_new_run --async-nn --paced

# 保留原计算路径，同步NN用于严格同输入检查。
python core/run_fast_structure.py --raw E:/dataset/train/6/media/event.raw --start 110 --duration 2 --output ../output/my_reference --reference-compute --paced --verify-frames

# 实验：把不改变规则的SDK过滤移入解码进程。
python core/run_fast_structure.py --raw E:/dataset/train/6/media/event.raw --start 110 --duration 4 --output ../output/my_prefilter --prefilter-decode --async-nn --paced
```

输出目录必须是新目录。帧哈希验证有额外开销，预览也会增加写盘与绘制成本。异步NN的回包时机受调度影响，不能把异步版与同步版当逐帧相同观测；异步的最终检测质量单独评分。

下一步优先减少主流程几何与周期处理的重复扫描、检测回包尖峰，并将谐波重发现降到独立慢速分支，局部证据只更新可观测方向。仍需同时看完整输出率、延迟尾部和准确度；当前尚未证明稳定30FPS或新增检测精度收益。
