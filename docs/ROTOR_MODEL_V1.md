# 五圆／可见性观测模块 v1

这是当前可以单独调用的**桨叶几何观测后端**。输入是项目原生ON/OFF前端已经提取的当前椭圆/弧段及周期测试，输出可直接供跟踪器、预测器或可视化消费。它本身不加载NN，不是一个新神经检测器；上游ROI可以来自纯桨叶前端，也可以来自NN辅助定位，必须区分说明。

## 当前能做什么

| 当前证据 | 输出 | 不会声称 |
|---|---|---|
| 四个合格区域 | 无序当前频率平方和（周期均合格时）、四点布局中心候选 | 桨数一定正确、真实COM、牛顿推力 |
| 三个合格区域＋近期完整布局 | 用共享平移稳定中心；当前形变需要时才调用已有形状检查仿射；补点标为推断 | 补出的第四桨有实测频率 |
| 两个区域或近线 | 当前方向／周期代理与带时效的先验；完整中心可拒绝输出 | 两点唯一恢复3D姿态、永远持续锁定 |
| 没有可信当前证据 | unresolved／prior不可用 | 靠历史假造当前检测 |

`RotorEvidence`区分当前区域数、周期合格数、时间支持、模板是否锁定和可测贡献。四桨全和不需要持久电机ID或完整模板锁定；完整物体模型仍用于补点和中心恢复。

`VisibilityLayout`当前选择：

- 四点：对角线交点作为弱透视布局中心候选。
- 三点：近期布局下的共享平移，最大参考年龄.4s；不能用三点直接平均替代整机中心。残差超过已有6px尺度时，才尝试项目已有仿射/形状门槛。
- 两点／侧线：不伪造完整中心，`current_center=null`；`prior_usable`明确时效，`prior_is_current_measurement=false`。

所有布局点都是图像中的几何量。透视、桨盘中心拟合误差、机体与桨平面的高度差等仍存在，不能把它们叫物理质心或姿态真值。

## 调用

在仓库根`D:/drone forecast/event_drone_forecast`内，使用已有Python环境：

```python
from rotor_evidence import RotorEvidence, VisibilityLayout

evidence = RotorEvidence()
layout = VisibilityLayout()

# 在原生ON/OFF前端每次当前观测之后调用；t严格递增。
packet = evidence.step(t, body, structure, current_rotor_arcs, current_period_tests)
state = layout.step(packet)
# state['current_center']可能为None；不得以prior冒充当前测量。
```

也可对已有原生入口输出执行：

```powershell
python tools/rotor_model169.py --input "<原生输出目录>/predictions.jsonl" --output "<新的模块输出目录>"
```

输出`rotor_model.jsonl`和`summary.json`，不加载权重或坐标标签。它复用仓库的`five_circle_model.py`等工具，不能只复制单个文件就宣称所有依赖已打包。

已有示例：

- `D:/drone forecast/output/decision169_20261105/exports/clear`：120次原生候选，ROI来自既有NN辅助，20次完整布局、4次近期三点中心；这不是120次真值验证。
- `D:/drone forecast/output/decision169_20261105/exports/pure_side`：60次纯桨叶原生入口输出，不用NN；侧视提供方向/局部周期，不能恢复的中心明确为空。

## 已有的有限证据

使用20个合格完整四区域帧，其中16帧有两份近期历史参考，逐帧隐藏四个中心中的一个，形成64个**受控缺测几何案例**。当前被隐藏的中心与完整布局中心只用于评分；模型只看到三个当前区域与过去布局，不使用当前NN机体位置。

| 方法 | 相对完整检测布局的中心一致性均值 |
|---|---:|
| 三点直接平均 |21.258px|
| 只有过去两次完整布局的速度预测 |0.837px|
| 近期布局＋共享平移（本模块默认） |0.325px|
| 原有更复杂仿射模型 |0.348px|

64例均有输出。原仿射补出的隐藏中心相对被隐藏检测点误差均值1.010px。

**这些不是0.4s运动预测误差，不是实际像素遮挡检测精度，也不是真实COM误差。** 参考来自同一帧完整检测布局，候选本身可能有误且包含先验条件化弧拟合；ROI上游用了NN辅助。测试说明结构可减少缺测组成变化带来的中心偏移，不能证明已解决真实遮挡或首次发明了刚体跟踪。共享平移已与仿射相当，不需要为复杂度本身继续堆算法。

## 推力分支的结论

169进行了一次固定时间划分、标定后冻结的对齐／置零／过去.4s错时序对照，未稳定胜过两个控制或未标定基线。此版本不再在这些旧片段上调推力响应系数。

该试验使用了标定段人工终点，属于特定低维响应头的监督诊断，不是所有模型的数学上限，也不是无需日志的RAW部署成绩。未知力可以快变，当前混合周期与真实推力之间的映射仍未证明有效。所有代码与负结果保留，推力分支标记为experimental。

## 可以准确描述的项目贡献

“实现了面向事件相机四旋翼的可见性条件化桨叶观测模块，区分当前实测、历史补点和侧视不可观测量；在真实视频候选的受控单桨缺测一致性测试中减少了直接可见点平均造成的布局中心偏移，并提供原生事件前端、JSON接口和可复现实验。”

不应写“稳定30FPS/30px”“真实推力已恢复”“无真值自动学出质量和推力系数”或“提出首个五圆/刚体模板方法”。具体新颖性和真实遮挡收益还需独立数据与已有方法对照。
