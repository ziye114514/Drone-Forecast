# 第十四阶段（目录名 stage143）：侧视周期量的局部化、可信度与运动状态实验

2026-10-24。目标：让侧视的方向/周期信息真正提高预测精度，同时保住平稳飞行与短时预测。结论：**没有找到可泛化的增益**；本目录保留全部负结果与两个可复用的诊断工具。

## 两个可复用的诊断工具

1. `regions143.py` + `capture143.py`：在冻结运行的机体 ROI 内把逐像素频率聚成局部假设并跨帧跟踪。侧视 475 tick 上得到 29 条轨迹（最长 186 tick @272 Hz、log 标准差 0.04）、同时刻频率离散中位 1.165、谐波歧义 0/336。**观测层可用，但没有转化成预测增量。**
2. `dense_score.py`：用“未来观测到的机体中心”作参考，给每个 tick 打分（侧视 n≈332 @0.4 s）。稀疏人工框只有 10 个端点，无法区分机制与巧合；稠密基准能，而且它直接推翻了速度守门（56.58 → 60.29）。

## 关键量化事实

- corr(dΣf²/dt, a·n) = 0.050；corr(Σf², a·n) = 0.029。节流代理量解释不了图像加速度（|a| 中位 828 px/s²）。
- 侧视线方向的方向性：median |a·t|/|a| = 0.945、|a·n|/|a| = 0.328（随机方向基线 0.710）。**推力投影若要用线，应该用线方向而不是法向**——但即便如此也没有预测增量。
- 框中心偏置 = 线中心 − 框中心：逐 tick 变化中位 5.05 px（≈250 px/s），|offset| 中位 8.7 px。**是逐帧噪声，不是慢变状态**，因此“独立偏置状态”没有可用余量。
- “滤波滞后”在**真实硬加速**与**框跳变污染**两种情况下不可区分（train1 的比值 0.17/0.53/0.49 与 continuous6 同量级）。单边版本（只许改大）两个收益同时消失，证明原收益来自“把速度降下来”这个动作本身。
