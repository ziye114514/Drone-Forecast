# 141：周期支持的侧视线观测

复用79的`native79.engine('strict7')`、原SDK数组布局适配/校验和`summarize`，再用现有`geometry._line`。当前20ms每像素一票，60—1200Hz、16像素、0.35模态占比和ROI/环带密度规则均沿用79，线宽比0.14沿用几何模块。以当前机体CV速度把本时刻周期像素对齐到当前时间。输出无向线/两种法线符号候选，**不输入预测器**。

主入口加`--periodic-axis`可用，默认关闭。实际侧视475时刻：332次合格周期ROI、235次线候选；预测与140逐项精确相同。没有独立姿态/机械RPM真值，不称235次正确姿态。完整视频与统一报告位于`D:/drone forecast/output/stage140_visible_fallback_20261024`。

已知条纹77/80、移动条纹20/80线候选，说明快速像素运动仍明显影响输出。四种子共同闪烁/Poisson/有色随机/突发无合格ROI；切频76/80周期合格但没有线。都是已知像素过程，不能外推真实无人机误报率。

重新查阅DDHF（https://arxiv.org/html/2603.08386v1）与FrequencyCam/EE3P；本轮没有运行DDHF，也没有采用FrequencyCam的IIR亮度重建。后续优先谐波/多电机来源和空间方向可信度，不能把主峰当四电机转速平方和。
