# 104：平移、机架投影与侧视退化

新增实验入口：`run_planar_center_forecast.py`，仅输入 RAW、已安装运行环境和项目原检测权重。原93的55路保留，追加5路；默认54不变。

`rigid104.py` 实际复用58的四共面圆联合锥曲线拟合，以及49的投影几何。四桨当前可见、几何条件和轮廓一致性合格，连续5帧后初始化。状态分别保留几何中心、四桨布局、初始图像位置偏置和新鲜度。变化归于当前平面投影，不使用“无人机应静止”的先验。

中心校正首次对齐到当时整机框，之后此偏置固定。它支持相对位置对照，不是对真实重心做了标定。布局参数的半径/面积尺度比在初始化后固定，仅接受一致的更新；形状和法向仍需当前观测。

侧视/缺桨时保留最后校正160ms，300ms归零，500ms无合格四桨则重新初始化；此时依靠当前整机位置与运动滤波。虚拟桨心仅供绘图，不生成频率或位置测量。不能仅凭一帧保证任意长遮挡跟踪。

`online104.py` 分别运行校正中心KF、历史加速度，以及按视角条件混合椭圆/整机线法向的有效力分支。新分支独立学习有效增益，保留恒定强度/零修正控制。没有米制推力、质量、风速、真实RPM或3D姿态输出。

`study104.py` 冻结参数、仿真、当前特征缓存复算、真实RAW及真实RAW截断前缀，最后才读稀疏未来位置标注评分。`matched104.py` 补充相同body-only时间戳/滤波器对照，避免把位置来源差异当成机架模型收益。
