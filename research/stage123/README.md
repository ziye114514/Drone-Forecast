## 实际发现

- 两扩展片段首次结构学习均0。1号四桨候选25次，完整几何资格仅1次，未能5次确认；2号没有四候选，25次只留2候选。
- 2号稀疏有目标8时刻NN均检出，目标中位约189×79px，中位IoU含漏检.8415；当前事件桨盘支持没有转成四圆结构。
- 6号22.8秒学到结构，400时刻中当前模型236次，包含6次自然三桨更新，自检224次；三候选40次中自检选择仿射6、回退34。没有连续5时刻的三桨有效跟踪并恢复四桨，三个正例完整自然恢复总数0。
- 名义.4秒对同组人工未来框中心：1号84.190px（1/2端点），2号71.099px（6/8），均无结构收益。6号bodyKF40.799px、原结构hold34.396、affine3/自检33.679、conic3为34.569px（11/11）。真实h约.4006—.419s，采用target−origin实际h外推，没有插值GT。
- .4秒自检相对原hold仅约.717px，等于始终仿射，不能归因为自适应选择独立收益。旧模型完整四桨几何本来就有作用，不能将其全部改善算本轮创新。
- 人工框是可见框中心，非COM/姿态/RPM；样本稀疏、历史已暴露，非前沿成绩或泛化证明。上一轮2.26px是完整模型一致性，不是本轮FDE。

## 提取链路取证

`trace123.py`复用110及109记录机制，对2号同300时刻重放。43.5秒候选仅12.17×6.63、11.39×4.41px，分组拒绝；45秒三个候选20.38×11.35、18.39×7.11、14.24×6.06px，仅选2个。最终桨盘序列严格等于原122。

43.5秒同一NN框扩大50px的区域：ON/OFF均出现像素3215、计数阈值mask165、opening157、closing161；45秒2259/357/352/355。不同支持定义不能当真实桨盘损失率，且包含机体/背景。原生“黑”只表示两极性出现；20ms计数归一到10ms后，每极性偶发一两次并不达到最低2.0密度门槛。图像与日志支持“密度门槛把支持压成小内核、随后候选和分组不足”的判断，不据此强行补四点或降低资格门槛宣称成功。

下一步优先用纯ON/OFF占据支持与现有重复计数分支作固定对照，复用已有NN ROI/弱边界/审计工具，比较首次建模率、轮廓完整性及空场/机体边缘误检。基础二值占据和阈值不是创新；应在提取可用后再论证122模型适配性自检的独立贡献。
